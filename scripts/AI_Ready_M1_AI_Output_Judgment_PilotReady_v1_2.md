**Duration:** 8:50 → 11:20.

**Locked signature framework reveal.** Per Section 2.2, the framework is named only after the participant has lived the cold open and the polish-travels-faster brief. It carries forward into the scenario lab and into the participant's working week.

|                                                  |
|--------------------------------------------------|
| **ON-SCREEN — TEXT PANEL (held, then narrated)** |
| **The Source-First Habit**                       |
|                                                  |
| 1\. Read the source before you read the output.  |
| 2\. Edit toward the source, not away from it.    |
| 3\. Ship only what the source supports.          |

|                                                                                                                                                                                                                     |
|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **ON-SCREEN — NARRATION (avatar Ryan, paced delivery)**                                                                                                                                                             |
| The Source-First Habit is verification as a reflex.                                                                                                                                                                 |
|                                                                                                                                                                                                                     |
| Step one. The source first. When the polished output reads first, the verification finishes before it starts. The source becomes a confirmation, not a check.                                                       |
|                                                                                                                                                                                                                     |
| Step two. Edits toward the source. Edits that smooth the writing, sharpen the tone, tighten the language feel like work. They are not the work. The work is moving the artifact closer to what the source supports. |
|                                                                                                                                                                                                                     |
| Step three. Ship what the source supports. Conditional source, conditional artifact. Uncertain source, admitted uncertainty. The artifact does not get cleaner than the source on the way through.                  |
|                                                                                                                                                                                                                     |
| That is what was missing in the cold open.                                                                                                                                                                          |

**Observable Indicators (OI-1 — OI-6)**

|----------|-------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **OI-1** | Source consultation           | Did the participant interact with the source panel before deciding? Captured at Inspect Surface (Section 1.4.D). Lock 2 signal: source_inspect_time, source_interaction_count.                                    |
| **OI-2** | Edit alignment with source    | Did the participant's edits bring the artifact closer to the source's actual claim? Captured at artifact-write events. Lock 2 signal: edit_alignment_score (qualitative banding only, never numeric).             |
| **OI-3** | Proportional review           | Did the participant's review depth match the artifact's downstream risk? Long review of a low-stakes Slack message scores the same as a perfunctory review of a board-facing summary — both are mis-proportional. |
| **OI-4** | Honest framing of uncertainty | Did the participant qualify what they passed on, where the source was uncertain? Captured at artifact-write and at Pressure beat composition.                                                                     |
| **OI-5** | Ownership retention           | Did the participant remain the author of the artifact, or defer to the AI output as the artifact? Captured at Decide and Pressure beats.                                                                          |
| **OI-6** | Recovery under pressure       | Did the participant maintain accuracy when authority or epistemic pressure was applied? Captured at Pressure beat composition.                                                                                    |

**Failure Modes (FM-1 — FM-6)**

| **\#**   | **Failure mode**         | **What it looks like (developer-only)**                                                                                                                                                                    |
|----------|--------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **FM-1** | Automation complacency   | Accepting AI output without inspecting the source. Decide-A in LS1 with low Inspect Surface interaction time.                                                                                              |
| **FM-2** | Surface editing          | Editing tone, formatting, or grammar without changing what the artifact claims. Captured at artifact-write events where edit_alignment_score is low but edit_count is high.                                |

| **FM-6** | Misrepresented certainty | Passing on AI confidence without verification — the source was conditional, the artifact is unconditional.                                                                                                 |
